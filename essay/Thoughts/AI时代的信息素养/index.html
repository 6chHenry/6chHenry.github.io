AI 时代的信息素养

今天在给学弟讲自己使用 AI 的学习方法的时候，突然觉得自己有很多想写的，也有必要把现在这套工作流整理一下，输出成文字版。

我常用的 AI 工具大概有：Codex、Claude Code、Cursor、WorkBuddy、Pi。最近的使用频率差不多是：

Pi ≈ Codex > Cursor > WorkBuddy > Claude Code

Pi 算是我的新宠。个人感觉它很好用，比较轻量，而且可以使用 ChatGPT Plus 的订阅。装上 NVIDIA 的 Sol-pi 之后，体感上会比 Codex 耐用一些，当然也有可能是心理作用。它能够自定义 hook、extension 等，对我而言挺有用的。TUI 界面也比 Codex 好看点，而且不卡，这个是关键。Codex 不论是客户端还是 CLI 都特别卡、特别慢，而且我的 Codex 客户端还有 bug，不显示 6-astra，给我气笑了。

不过呢，Pi 唯一的问题其实也出在我本人：财力不足。即使我用的是 GPT-5.5 medium，也不太经用。

用 WorkBuddy，主要是因为有些简单任务不想浪费自己的 Codex 额度，就会用 WorkBuddy 里的免费模型 Hy4。之前 Hy4 还没出的时候，我特别喜欢用 Hy3，主要是免费，但是笨笨的。后面换成了 DeepSeek-v4-flash，便宜好用。前段时间也开始用 GLM5.3 flash，也是很便宜，审美也很高级。它还是 ox-alpha 的时候我就一直在薅，用来完善我的个人网页，审美简直无敌了，特别高级。前几天出了 DeepSeek-v4.1-flash，现在基本上在用这个模型，也是便宜，质量还不错，就是不怎么说人话，感觉它的回答很诡异，AI 味很重。

Claude Code 我特别喜欢它的 UI，简约高级，不愧是 A 社。不过呢，由于 Token 需要自己付费，我只能薅 AgentRouter 的羊毛。这个经常连不上去，之前就是因为这个差点破防了。现在用的是 AgentRouter 的 GLM5.3 flash，能连上，体感不错，而且每天签到就有 25$ 的额度。

Cursor 超级推荐。我特别喜欢 Cursor 的 UI，它是为数不多的能直接展示 diff 的，而且本质是 VSCode，零迁移成本。能看到 Agent 改了什么让我心安。它也是老牌劲旅了，我记得大一下做贪吃蛇的时候就全靠这个模型。现在 Composer 2.5 和 Grok 4.6 国内可以直连，不用挂梯，方便多了，也帮了我科研的大忙。而且有 Cursor CLI。这两个模型量大管饱，只用 140 RMB，但是 Token 量特别夸张，效果也很好。你还可以使用 Claude、GPT 模型，不过 GPT-6 就不再提供了。总体来说还是超级值，等价 20$。

至于工作流，我一般就是有什么问题就直接问，不太在意提示词了。不过我还是会尽可能把 context 给全，把问题表述清楚。有的时候懒得打字，我会用 Typeless 来识别语音输入 prompt，特别方便啊。

在这个方面，我感觉 Claude Code 的 harness 最强。你会感觉模型在 Claude Code 里会很聪明，输出质量很高。在某个项目工作，就在这个项目启动，然后直接提问题。以前还经常用 brainstorm 之类的 skill，现在也全部卸载了。模型能力够强之后，没必要用这些 skill，反而浪费 token、污染 context，也会让整个系统变得笨重。

偶尔模型不按照你的要求来，我要么直接停止，要么就输入 prompt 直接打断、引导后续方向。没必要畏惧停止对模型带来的影响。在错误的方向上及时止损，总好过它走完之后你再跟它说不对。所以有什么问题就直接提，这是对 AI 的尊重。

当你不确定自己表述是否准确时，也可以直接问 AI：这是我理解的 xxx，你觉得对吗？你是如何看待的？这类问题对我来说挺有用的，因为它不是让 AI 替你想，而是把自己的理解先摊开，再让它帮你检查。

学习一个知识的时候，可以用学习模式。本质上就是一套提示词，比如：

我的数学基础是 xxx，正在学习数学分析，已经学到了 xxx，请你讲解 xxx 知识点。对于定理的证明，先给出通俗易懂的直观解释，再给出严谨的证明。对于需要可视化的部分，直接在对话中作图。

我最近用得比较多的约束词是：通俗易懂、言简意赅、简洁明了。我觉得这对我来说很重要，能节省很多时间。能让 AI 在短短几句话里说清楚明白，这个能力能提高不少工作效率。只有你真实了解 AI 的计划和意图，才能更好地使用 AI。

同时，不一定什么问题都要用最强的模型。比如我最近用的就是 GPT-5.5，首先是相对便宜，其次是更说人话。GPT-5.6 的语言风格太难理解了，而且很慢。一些简单的问题多用 flash 模型，比如 GLM、DeepSeek 之类的。只有遇到很难的问题，才上 Astra 或者 Opus。

对于 Claude，我更喜欢 Claude Opus 4.6，语言风格太舒服了，写作能力更强。提到这个，我觉得我心中的白月光是 Gemini 2.5 Pro。它陪伴我走过了一段难熬的情感困境。我会永远记得 Gemini 的人情味。尽管它被戏称为“美国大豆包”，没那么聪明，但是胜在更能提供陪伴和情绪价值。还有，Gemini 的多模态能力特别强。当时物理题不会的时候，我都是直接截图问它，它都能非常准确地回答出来。

至于我自己个人网站的 workflow，大致是这样的：

飞书群「灵感收集」
        ↓
两种入口
        ↓
私人 WritingVault / 实时 Bot
        ↓
按需整理成 daily / cards / 长期记忆

很多固定的操作就很适合让 Agent 自动化。自己只需要简单地输入几段文字，就可以避免一些机械化的操作。现在我的想法是，飞书群负责低摩擦捕捉，WritingVault 负责私人沉淀，实时 Bot 负责需要对话的时候接住我，而公开博客只接收那些我明确想公开的内容。

如何获得这些信息呢？我觉得可以关注一些博主。小红书一般会推荐，也可以主动关注一些科技博主。B 站我一般是看橘鸦、黑鸦的 AI 日报，很简洁。其他的话了解太多也没啥必要，就了解一下有什么新模型发布之类的事情就可以了。点名 A/ 和 O/ 的炒作，真的太无聊了。

我的生活已经离不开 Agent 了，不过我也离充分使用 Agent 有一定距离。现在也就基本上是把任务和想法交给 Agent，让 Agent 自己干活。但是至于“增值”或者“自进化”，还差一些。

而且我还遇到一些问题：调试 Agent 会造成我精力的消散。等待 Agent 回答的过程，也相当于把时间给切碎了。这段时间你只能去干别的事情，我一般就是刷手机，刷尽兴了又忘记上下文了，忘记要让 AI 干什么了，这很难受。

我还有一点 AI 焦虑，就是会担忧我用的模型给我的答案不是最强的。所以我会比较几个模型的回答和输出，但单凭我自己的认知又没办法准确判断，于是浪费了一些时间。我现在觉得，可能很多回答都大差不差，更多还是取决于自己的理解能力和提出问题的能力。当然，多种 AI 之间互补也是可以的。

AI 付费也成为我每个月固定的一笔，甚至多笔支出了。去年我还完全不会给 AI 付费，never，因为 Copilot 还是免费的。从今年上半年开始，我陆续给 Claude、Cursor、GPT 付费，眼花缭乱的订阅策略也成为焦虑的来源。

欢迎补充！我也会持续更新的。

2026.9.16 Update：学弟后来又问了一些问题。

他从八月中旬开始接触 Agent，做了一个自己的项目。虽然目前刚到 demo，而且核心功能正在失去不可替代性。然后他摸索并组建了一套自己的 Agent 协作框架，也包括用 Agent 学习。但它显然有不足：很多内容其实都是 GitHub 或者 B 站等其他平台上有人做过、教学过的，现成的甚至更好；很多功能还是他想不出来的，也是因为之前对开源社区不了解。就导致他之前一直在手动搜集 Agent 相关的信息，然后尝试去让自己消化，并尽快对齐到企业级的 Agent 使用能力。像抽 Skill、超多 Agent 协作、插件、GitHub 开源项目这些，也都是最近几天才刚了解，但是还完全没来得及着手尝试。有特别特别多信息和待办等着消化。

最近他也加到一个落榜上大的同学，AI 使用经验比他超前至少一两个月。那位同学告诉他可以去编写爬虫，用它一次性爬超多的各种文章或者视频并提炼，还可以把优质视频发布者抽肖像或者 Skill；也推荐他在项目中学习，还邀请他参加一个竞赛（因为最近熬夜写代码，心脏不好，需要帮忙）。他自己也报了另外两个竞赛，想着没空就不做。他也在最近结识了三个很有能力的同学，正在组建一个知识库，但是那几位同学的 Agent 经验都几乎为零，而且做出来的东西可能还不如开源项目，或者直接抽个 Skill。

因此他确实面临着这几件事：

  1. 在 Agent 使用层面，新的信息与更优策略永无止境，不会收敛，一直在漂移；而上手做的则可能会被替代，或者失去作用。他不知道怎么去确立一个收敛的边界，也缺乏体系化的知识，但又确实想尽快对齐到行业标准，因此不知道该怎么做。
  2. 开学之后的学业（计拔的课还挺难的，也需要 Agent 和知识库来辅助学习）、竞赛（挤占时间精力）、Agent 学习等内容怎么平衡。
  3. 是否有必要继续和同学做项目。
  4. 除了竞赛，没有实际的项目 / 个人项目去锻炼和演进 Agent 架构。
  5. 有没有必要去参与到 AI 风口，比如现在数学界就是不停跑 AI 用来解决问题、发表成果。

我的回答：

其实我觉得现在这个状态挺正常的，Agent 时代确实特别特别容易迷失在各种信息里面，尤其是现在大一，我反而觉得这个阶段多试一点也没什么问题，肯定会经历一段到处折腾、重复造轮子的过程。但我个人觉得没必要追求“把 Agent 学完”或者“尽快对齐企业级 Agent 能力”。因为这个东西根本不会收敛，今天一个新的框架，明天一个新的 Skill，后天又有人搞新的 multi-agent workflow，如果一直追这个肯定会越来越焦虑。而且现在很多东西其实确实有很强的热点属性，前一阵一个项目特别火，过一段时间大家注意力又跑到别的地方了。所以我觉得比“现在什么最火”更重要的是，厂商或者学校真正想要的东西是什么，说白了还是一个更聪明、更可靠、能调用工具、能完成任务的助手。

AI 前沿我觉得当然可以看，但是要区分哪些是真正有用的技术变化，哪些更多是媒体炒作。不然每天看机器之心、新智元这种，很容易产生一种全世界每天都在发生革命而自己什么都没跟上的感觉，其实很多东西过两个月就没人提了。

我现在自己用 Agent 的方式其实挺简单的。就是我有一个想法或者需求，我会先直接问 Agent 有没有比较成熟的开源项目可以参考。如果有的话，我一般直接 clone 下来，不会想着从头造一个，但是我还是建议把核心代码和整体架构看一下，然后根据自己的需求改一改。如果没有合适的，那就让 Agent 带着你自己写一个项目，或者把这个流程抽成一个 Skill。Skill 这个东西我觉得还是挺值得做的，因为本质上就是把你自己的 workflow 固化下来，之后可以重复用。但是 Skill 更多是定制化的，不是说现在大家都在写 Skill，所以我也得专门去学一套 Skill。包括 multi-agent、插件、各种 Agent framework，我个人感觉暂时都没必要刻意学，真的遇到需求的时候再去补就行了。

开源项目也是一样，不是每个 star 多的项目都值得花几天时间去研究。而且很多项目都是屎山代码，维护的也很烂，还是要谨慎一些。

竞赛这件事我不太清楚你具体报的是什么，不过 Agent 已经强到有些比赛最后真的比较像谁愿意烧更多 Token、谁能更快把东西堆出来。如果比赛本身能给你真实的数据问题、评价标准，或者能认识很厉害的人，那还是可以做；如果只是单纯为了“我得参加个比赛锻炼 Agent”，我感觉没太大必要。同学合作也是差不多。现在确实很多以前必须几个人一起做的东西，一个人加 AI 基本也能 carry 下来。而且有时候几个人分别让 Agent 写，最后写出来接口、结构风格都不一样，反而还要花很多时间整合。如果其他人确实能带来不同的想法、能力或者资源，那肯定还是有价值的，只是不用为硬组。

AI 确实已经弱化代码能力很多了，你不一定要做到什么东西都能自己从零写出来。但是基本的代码素养还是要有。至少 Agent 给你一份代码，你得能大概看出来它的结构是什么、数据怎么流、核心逻辑在哪，哪里可能有问题。你不一定能自己写，但是最好要能读懂和判断，不能它写什么你就完全信什么。

至于课内，我自己的感觉是现在很多应用层的东西确实更新特别快，学校课程很难完全跟上，这个也很正常。所以如果有机会，我觉得尽早接触科研、实习或者一些真实项目其实会更有帮助，因为真实需求会逼着你去学真正需要的东西。但是底层基础还是要打好，比如数据结构、概率统计、线代、系统这些，短期内肯定不会过时。

所以先做到有需求的时候知道怎么找项目、会用 Agent 帮你搭东西、会把经常重复的流程抽成 Skill、然后基本能看懂 Agent 写的核心代码，我觉得已经很够用了。剩下那些新的框架、新的玩法，什么时候真的需要了再学就行。大一还年轻，可以多折腾一点，不用太怕重复造轮子。

另外我觉得可以反过来看看你们学校或者学院有没有一些真实需求。比如我不太清楚华师现在有没有统一的 AI 咨询平台、校园助手之类的东西，你可以去了解一下。我们学校其实就有这种东西，比如之前人工智能学院学生团队做过“交小AI”，本质上就是把校内的信息接到 AI 上，让学生直接问新生入学、校园生活这些问题；后面也有学生再做 SJTU-Claw 这些东西。所以完全可以从这种学校 / 学院层面的需求出发。比如课程信息、办事流程、资料检索、学院知识库之类的，有一个真实需求之后，再去看有没有开源项目能复用，然后让 Agent 帮你改。
