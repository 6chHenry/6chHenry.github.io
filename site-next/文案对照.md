# 文案对照

这是站点 **UI 外壳文案** 的对照底稿，改这里即可，不用先改代码。请直接编辑「改后」：写成你想说的话；若这句不该出现，把改后写成 `（删除）`。

收录：导语、入口说明、空状态、页脚旁白、搜索提示、路径解说、苔苔台词等「站在旁边解说网站」的句子。未收录：笔记 / 杂谈 / 作品正文、关于页自我介绍、学术主页履历事实、画廊各城照片说明与藏头诗、项目案例正文。导航词（主页、笔记、搜索按钮）也不在此列。

来源：`site-next/`（Astro），不是 MkDocs，也不是 git 仓库里的 `docs/`。

口气：像人说话，可以有一点文学；不要像在解说自己的网站，也不要像生成的森林宣言。原来的隐喻，人会那么说的就留。
